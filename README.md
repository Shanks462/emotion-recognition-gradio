# Emotion Recognition System 🎭

This project detects human emotions from facial images using a CNN model trained on the FER2013 dataset.

## 🧠 Model
- Built using TensorFlow & Keras
- 7 emotion classes:
  - Angry
  - Disgust
  - Fear
  - Happy
  - Sad
  - Surprise
  - Neutral

## 📊 Training Details
- 20 epochs
- ~70% training accuracy
- ~56% validation accuracy

## 🚀 Live Demo
Deployed using HuggingFace Spaces + Gradio

## 🛠 Tech Stack
- Python
- TensorFlow
- OpenCV
- Gradio
